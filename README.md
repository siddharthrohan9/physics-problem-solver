# Physics Problem Solver & Simulation Tool

A Python-based physics application for solving projectile-motion problems and visualizing projectile trajectories.

## Features

- Calculate projectile time of flight
- Calculate maximum height
- Calculate horizontal range
- Validate user inputs
- Generate projectile trajectories using NumPy
- Visualize trajectories using Matplotlib
- Automated testing using pytest
